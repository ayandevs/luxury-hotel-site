# 🏨 Luxury Hotel Website

## 📖 Description

A clean and responsive luxury hotel website featuring hotel information, room imagery, availability checking, navigation controls, and social media integration.

## ✨ Features

- Luxury hotel branding
- Image slider navigation
- About Company section
- Room availability form

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## ▶️ How to Run

1. Download or clone the project
2. Open the project in a code editor
3. Ensure all images are inside the "images" folder
4. Open "index.html" in a web browser

## 🚀 Future Improvements

- Functional image slider
- Real-time room availability
- Online room booking
- Backend integration
